Configuración de Google Sheets (Nube)

Al pegar la URL de tu Google Apps Script Web App, las evaluaciones de los profesores se guardarán directamente en tu Google Sheet personal en cuanto den clic en "Confirmar & Guardar Evaluación".

Instructivo de conexión rápida (3 minutos):

  1. Abre tu **Google Sheet** y ve al menú superior: Extensiones → Apps Script.
  2. Borra el código existente y pega el siguiente script:
function doPost(e) {
  try {
    var sheet = SpreadsheetApp.getActiveSpreadsheet().getActiveSheet();
    var data = JSON.parse(e.postData.contents);
    
    sheet.appendRow([
      new Date(),
      data.evaluator || "Anónimo",
      data.teamNumber || "",
      data.topic || "",
      data.finalScore || 0,
      data.recommendation || "",
      data.qualitativeScore || 0,
      data.processScore || 0,
      data.rubricScore || 0,
      data.comments || ""
    ]);
    
    return ContentService.createTextOutput(JSON.stringify({ "result": "success" }))
      .setMimeType(ContentService.MimeType.JSON);
  } catch (err) {
    return ContentService.createTextOutput(JSON.stringify({ "result": "error", "error": err.toString() }))
      .setMimeType(ContentService.MimeType.JSON);
  }
}
  1. Haz clic en el botón azul Implementar → Nueva implementación.
  2. En *Tipo*, elige Aplicación web.
  3. En *Quién tiene acceso*, selecciona Cualquier persona (*Anyone*).
  4. Haz clic en **Implementar**, autoriza los permisos y **copia la URL de la aplicación web** obtenida para pegarla en el recuadro superior.

Acceso Móvil Evaluadores

Los profesores pueden escanear este código con la cámara de su celular para abrir el formato de evaluación.
